# Pawmetry publishing checklist

Use the existing [GitHub repository](https://github.com/RenzAngelo/pawmetry) and Marketplace extension ID `renzangelo.pawmetry`. The Windows x64 VSIX is free and marked as a pre-release. GitHub hosts source and optional manual downloads. Marketplace delivers the VSIX to VS Code.

1. Start on a feature branch from `origin/main`. Review the version and release notes. The extension manifest, root manifest and lockfile must agree. Put Marketplace Details copy in [the extension README](apps/vscode/README.md) when available on the release branch. The v0.1.5 baseline generated that text during packaging.
2. Run `npm.cmd ci`, the [automated tests](TEST_PLAN.md), and `npm.cmd run package:public-preview`. The build produces a locally audited VSIX and `SHA256SUMS.txt`. Verify the exact artifact under a standard Windows account with security protections enabled. [Manual acceptance](MANUAL_TESTS.md)
3. After approval, merge the reviewed source through a pull request. Point the GitHub release tag at the reviewed source for the artifact. Publish a GitHub prerelease with the VSIX, checksum and release notes. Update the existing Marketplace listing with the same VSIX. [GitHub releases](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository) · [Marketplace publishing](https://code.visualstudio.com/api/working-with-extensions/publishing-extension#publish-an-extension)
4. After verification, check the public version and Details page. Install from the Marketplace in a fresh VS Code profile and confirm the companion launches. For updates, also verify the previous companion can hand off to the new version while retaining settings.

The Windows companion is unsigned. Document any Windows security blocks and keep protections enabled during testing. Experimental native activity is outside the public package. Release automation is deferred to the [roadmap](DEVELOPMENT_PLAN.md#follow-up-releases). [SmartScreen guidance](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation) · [Security notes](SECURITY.md)

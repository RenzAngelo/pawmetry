# Product brief

**Pawmetry** is the working name for an independent desktop companion for AI-assisted coding. Its tagline is “Your AI's pulse, brought to life.”

Developers, students and software engineers switch between editors, terminals and other windows while coding agents work. Pawmetry aims to make it easier to notice real activity and understand how much usage remains without opening the agent panel. A small animated pet shows the state at a glance, and VS Code shows the underlying numbers and source when available.

## Product experience

- Keep the pet on the Windows 11 desktop while VS Code is minimized. Let the user drag, resize, pause or hide it and recover from click-through using the tray.
- Represent supported short-term quota as energy and long-term quota as stamina. Make provider scope and availability clear in the dashboard. Keep an unknown state whenever data is unavailable, stale or ambiguous.
- Animate real agent events, such as tool work, only when the provider exposes reliable evidence. Preserve the user's control over any integration or hook configuration.
- Support one original character first, with sprite animation, size and speed preferences, and reduced motion. Provide an offline simulation for learning, demos and testing without consuming usage.

## Users and sequencing

| Audience | Need |
| --- | --- |
| Developers and students using AI coding assistants | See at a glance when the agent is active, waiting or finished when those states are verifiable |
| Agentic coding users | See actual available allowance and reset timing, including limits shared across clients |
| Privacy-conscious users | Understand and control each integration, with minimal local data and no default external analytics |

First target Windows 11 x64 and VS Code desktop. Start with OpenAI Codex research and validate Claude Code, GitHub Copilot and other providers independently. A provider can qualify for activity or usage support individually. The roadmap also allows future operating systems and user-supplied character assets.

## Success for the first product slice

The pet stays visible and controllable when the editor is minimized. The companion and dashboard agree on known quotas and activity, reflect loss of freshness, and clearly label simulation. A user can operate the product with standard Windows privileges and use simulation offline. The intended product is free and open source with original art. Trademark clearance and project licensing remain pending.

# Changelog

## 0.1.6 Marketplace listing update

- Added installation, quota, privacy, and feedback information to the extension's Details page.

## 0.1.5 Public Preview

- Published the Windows x64 VSIX as `renzangelo.pawmetry`, with the animated Cat mascot and approved Pawmetry logo.
- Published the tested package and checksum in the GitHub prerelease.

## 0.1.4 Single-install preview · prepared for review

- Windows x64 VSIX bundles the desktop companion and starts live Codex quota after consent.
- Persistent quota access lives in Settings under Connections. The tray retains pause and exit.
- The VSIX carries Marketplace pre-release metadata. Native prompt activity remains in experimental validation.

## 0.1.0 Public Preview · prepared for review

- Live Codex account quota as energy and stamina, with remaining percentages, local resets and countdowns.
- Independent Windows companion with pet-only, compact and dashboard views, saved positioning and sizes, pinning, tray recovery, themes, and reduced motion.
- Optional VS Code extension sharing the companion's quota over authenticated local IPC.
- Adaptive menu placement and Windows Settings and resize fixes.
- Portable Windows and VSIX packages with SHA-256 checksums. Native activity, advanced alerts, and other providers are deferred.

# Pawmetry artwork and branding

The Pawmetry logo was approved by the maintainer for the application. The dark and light vector masters and icon files live in `assets/branding/pawmetry`. The MIT source-code license excludes the Pawmetry name, logo, and mascot artwork. Public redistribution and trademark terms for those assets are tracked here. Third-party interface icons retain their original licenses. [MIT source license](LICENSE) · [Third-party notices](THIRD_PARTY_NOTICES.md)

Cat is the first official mascot. The supplied reference and draft atlas came from the maintainer’s ChatGPT Web artwork workflow. The production sprite sheet was repacked from the draft and contains 50 active frames. Only the validated sprite sheet and atlas metadata belong in the runtime. The original reference and draft remain outside the package. Future mascots can use the same atlas contract. [Animation specification](ANIMATION_ASSET_SPEC.md)

OpenAI’s consumer terms assign its interest in output to the user as between the parties, subject to applicable law. The maintainer confirmed that Cat was made using only ChatGPT on 2026-11-27. [OpenAI terms on content ownership](https://openai.com/policies/terms-of-use/#content)

The local visual review covered `Futuristic Pixel Cat Character Sheet.png` and `Futuristic Cat Robot Sprite Atlas.png`. The art depicts a consistent robot cat and contains no obvious third-party brand, signature, or watermark.

The maintainer approved sharing the production Cat mascot and the Pawmetry logo as part of Pawmetry, including modified builds. Standalone uses such as putting Cat in an unrelated app or on merchandise require separate permission. [Artwork distribution terms](assets/mascots/cat/DISTRIBUTION.md)

The preliminary name review found a 2024 Dallas Bark + Build doghouse entry named PAWMETRY. That entry is in a different field from downloadable developer software. Targeted indexed searches did not surface an exact-name competing developer tool or VS Code listing. Full clearance is open, including similar names and logos and national trademark registers for target markets. Start with Class 9 for downloadable software.

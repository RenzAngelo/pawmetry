# Pawmetry Public Preview

**See how much Codex quota you have left without leaving your work.** Pawmetry puts your remaining allowance in the VS Code status bar and brings it to life with Cat, an animated Windows desktop companion.

## Get started

1. Use **VS Code 1.109 or later on Windows 11 x64**. Install the local OpenAI Codex extension and sign in to it with ChatGPT.
2. Install the **Pre-Release Version** of Pawmetry from the VS Code Extensions view.
3. In a trusted local workspace, click **Start Pawmetry** in the status bar and confirm quota access. The desktop companion is included with the extension.

## What Cat shows

- **Energy** is your short-term Codex allowance. **Stamina** is your longer-term allowance. Check both remaining percentages and their reset times.
- Choose **Pet only**, **Compact**, or **Dashboard**. Move, pin, or hide Cat and adjust its appearance in Settings.
- Local VS Code windows share one quota monitor. Use **Settings → Connections** to manage quota access.

## Privacy and preview limits

Pawmetry runs locally and uses your existing Codex sign-in. It sends no prompts and includes no Pawmetry analytics. This preview shows account quota. Live prompt activity is planned for a future release. The Windows companion is unsigned, and Windows policy may block it. Pawmetry is an independent project.
